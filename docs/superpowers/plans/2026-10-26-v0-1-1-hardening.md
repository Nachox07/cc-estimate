# v0.1.1 Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make cc-estimate safe and honest to publish: no other person's data in any output, no crash on small or unusual histories, configurable branch and tracker keys, and an installable Claude Code plugin.

**Architecture:** Small fixes inside the existing modules, one new helper module (`cc_estimate/files.py`) for output files, and a plugin layout (`.claude-plugin/marketplace.json` at the root, the plugin under `plugin/cc-estimate/`). The CLI stays stdlib-only and installs with `pip`.

**Tech Stack:** Python 3.10+ standard library, `unittest`, `git`, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-25-hardening-measure-advisor-design.md`, section "Release v0.1.1". The v0.2 sections get their own plan.

## Global Constraints

- Python `>=3.10`; no third-party dependencies (`dependencies = []`). No `tomllib` (3.11+).
- Tests use synthetic data only. No real repository data, company names or real logins in the repo.
- Test names describe behaviour; no ticket or issue numbers in test names.
- No command prints another person's login or per-person numbers. Only the current user's own estimates are logged or scored.
- Run all tests with `python3 -m unittest discover -s tests -v` from the repo root.
- Commits use the noreply identity already configured in this repo (`git config user.email` must end in `@users.noreply.github.com`; check before the first commit).
- The repo stays private. Making it public is the owner's decision after this plan lands.

## Review Focus

1. **The history file is missing or empty** (a user runs `estimate` before building history): a one-line message naming the file, not a traceback. Tested in Task 5.
2. **Every task started inside the censor window** (a repo younger than 21 days): `estimate` and `backtest` say the history is too short. Tested in Tasks 5 and 6.
3. **An older config with `git.key_regex` as a single string**: still works after keys become a list. Tested in Task 3.
4. **A GitHub-source estimate logged with a tracker key** (`--issue ABC-1`): refused at log time with a fix, and an old log row with such a key is skipped by `score`, not fatal. Tested in Task 3.
5. **Mixed timezone offsets in commit dates** (authors in different zones): commits order by real time, not by string. Tested in Task 4.

```python
def merges(repo_dir, branch, since):
    """Merge commits on the branch's first-parent line, with the time each one landed."""
    fmt = UNIT.join(["%cI", "%s", "%b"]) + REC
    out = subprocess.run(["git", "-C", repo_dir, "log", branch, "--merges", "--first-parent", f"--since={since}",
                          f"--format={fmt}"], capture_output=True, text=True, check=True).stdout
    rows = []
    for chunk in out.split(REC):
        chunk = chunk.strip("\n")
        if chunk:
            at, subject, body = (chunk.split(UNIT) + [""] * 3)[:3]
            rows.append(dict(at=at, text=subject + "\n" + body))
    return rows
```

`build` becomes:

```python
def build(cs, patterns, ignore_re=None, merged=()):
    groups, skipped = defaultdict(list), 0
    for c in cs:
        if ignore_re and ignore_re.search(c["author"]):
            continue
        key = find_key(c["subject"] + "\n" + c["body"], patterns)
        if not key:
            skipped += 1
            continue
        groups[key].append(c)
    landed = defaultdict(list)
    for m in merged:
        key = find_key(m["text"], patterns)
        if key:
            landed[key].append(m["at"])
    when = lambda s: datetime.fromisoformat(s)
    rows = []
    for key, cl in groups.items():
        cl.sort(key=lambda c: when(c["at"]))
        authors = defaultdict(int)
        for c in cl:
            authors[c["author"]] += 1
        last = cl[-1]["at"]
        after = [m for m in landed.get(key, []) if when(m) >= when(last)]
        end = max(after, key=when) if after else last
        rows.append(dict(id=key, title=cl[0]["subject"], author=max(authors, key=authors.get), labels=[],
                         start=cl[0]["at"], end=end, end_kind="merge" if after else "commit",
                         lines=sum(c.get("lines", 0) for c in cl), commits=len(cl), excluded={}))
    rows.sort(key=lambda r: when(r["start"]))
    return rows, skipped
```
